Laboratório

Reações de perigo

Cenários detectados

Neutralização ácido-base, gás cloro, cloraminas, sódio com água, água oxigenada com detergente e saponificação.

Fisiologia

Órgãos afetados

Diagrama do corpo humano com órgãos clicáveis, que piscam conforme o nível de risco e mostram o tempo estimado de complicação.

Como usar

Requisitos: Node.js 18 ou superior.

  1. Instale as dependências na pasta do projeto: 
    npm install
  2. Inicie o servidor de desenvolvimento: 
    npm run dev
  3. Abra http://localhost:5173 no navegador. Escolha até três substâncias no catálogo, ou use uma das misturas rápidas para começar.
Aviso educacional. O ChemTox Engine é um simulador didático. Os valores de pH, temperatura e os indicadores clínicos são estimativas ilustrativas e não substituem laudos reais. Nunca misture produtos químicos reais para testar o que aparece na tela e, em caso de intoxicação, ligue para o serviço de emergência ou para o centro de informação toxicológica da sua região.
